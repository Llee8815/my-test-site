## Writing conventions

Use these conventions on every Wiki page so the site stays consistent.

### Headings

- Use `##` for main sections and `###` for subsections
- The page title comes from front matter, so don't add a `#` heading in the body

### Code

- Put commands and file names in `backticks`
- Use triple backticks for multi-line code blocks

### Front matter checklist

Every page needs:

1. A `title:`
2. A `layout:`
